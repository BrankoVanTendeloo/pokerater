==== FETCHING LIST ====
https://pokeapi.co/api/v2/pokemon/?limit=100000
(There are currently just over 1000 Pokémon, 100000 is enough)

Returns a list "results" of objects:
    • "name" includes the name ID
    • "url" gives another API URL to that Pokémon's page.
